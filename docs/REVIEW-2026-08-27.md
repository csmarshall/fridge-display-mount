## C. The instruction file contradicts the build

`CLAUDE.md` is the file every agent is told to trust, so its errors propagate.

- **C1 ×2 — §5 forbids the magnet actually specified:** "Not male-stud — a stud needs a nut on the
  display-facing side and breaks the flat mounting plane." The build is 3506K67, a **male stud**,
  secured by exactly that nut. The BOM asserts the opposite doctrine ("male-stud style is
  load-bearing"). One of these must go.
- **C2 ×2 — §4b "settled geometry" is stale on nearly every number:** spacing 250×240 (built 246),
  neck 310 (built 257), blank 742 (738.8), quote $185.85 ($197.07), arm rows "90 and 144" (fitted
  are 36 and 144), plus a whole countersink paragraph that is retracted elsewhere.
- **C3 ×2 — §1.5 contradicts itself in one paragraph:** "Validator bound is now −0.60 to +0.30 mm"
  then "the validator accepts 0 to +1.0 mm and rejects anything negative." The code implements the
  first. The second is un-deleted old rationale.
- **C4 — §3 still says "0.119" as built"**; §4 says orientation landscape, built is portrait;
  §1.1 says μ 0.7 rubber-faced, the code uses 0.2 bare nickel.

## D. Real numeric bugs (not just stale prose)

- **D1 — Washer max thickness is wrong in the generator.** `WASHERS` carries **0.060 in**; the
  verified McMaster range max is **0.069 in**. Consequence: the published row "thin nyloc + washer
  fits (+0.08 mm)" actually becomes **−0.15 mm, does not fit**. The specified jam-nut stack still
  fits at 0.069 (+1.44 mm), so **the order is safe** — but the fit table is computed on the wrong
  number, and 0.069 is the figure the decision was actually made on.
- **D2 — `mu_rubber` holds 0.2, not 0.7**, with a comment saying it is not rubber any more.
  `magnet_shear_rubber_lbf` and `magnet_shear_bare_nickel_lbf` are now identical duplicates in the
  report. One home per fact says: rename and drop the duplicate.
- **D3 — Upcharge is +$11.21, not +$11.71** (PRICE-STUDY ladder: $177.00 → $188.21). Digit swap.
- **D4 — `assembly_drawing_27in.svg` was never regenerated** after the thickness change; it still
  says 0.119 in / 3.02 mm while its 23.8" sibling says 0.187/4.75. The page links both.
- **D5 — 0.187 vs 0.188** for the same thickness. Both appear, sometimes on one page.
- **D6 — Foam: 11.5 mm modelled, 7/16" (11.11 mm) purchased.** 11.11 passes the validator, so this
  may be a deliberate imperial substitution, but nothing reconciles the two numbers.
- **D7 — `magnet_pattern_study` panel 3:** the second-row discs overlap the corner discs by roughly
  half a diameter. At the stated 54 mm row pitch Ø48 discs should nearly touch, not overlap.
  **Possible data bug rather than a drawing bug** — verify the pitch before restyling.
